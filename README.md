# EditorImageSync for Typecho

写长图文的时候，左边是一排图片链接，右边是一张张大图，滚着滚着就不知道写到哪一张了。

这个插件给两边的图片按顺序编上号，点右边的图，左边就跳到对应那条链接、光标停在链接后面，可以直接接着写。

## 安装

1. 把 `EditorImageSync` 整个目录上传到站点的 `usr/plugins/`。
2. 后台 → 控制台 → 插件 → 启用 **EditorImageSync**。
3. 打开写文章页，按一次 **Ctrl+F5** 强制刷新。

需要 Typecho 1.2 以上，并且用的是自带的 Markdown 编辑器。装了富文本 / 第三方编辑器插件的话，本插件会自动跳过，不影响后台使用。后台目录改过名也没关系。

## 怎么用

- **点右边预览里的图** → 左边滚到对应链接，光标落在 `)` 后面，接着打字就行；这一行会黄一下。
- **左边的小缩略图**：悬停看大图，点一下让右边预览滚到这张。
- **右下角「#N · 第 X 行」**：滚到大图中间也知道在看第几张。
- 全屏写作（Ctrl+J）左右分栏时最顺手；在「预览」标签下点图会自动切回「撰写」。

编号按图片在文章里出现的顺序算。一行多张图、同一个地址重复用、`<url>` 尖括号写法、`[photos]` 图集、中文说明加一长串网址的链接，都能认出来。

## 设置

后台 → 插件 → 设置，默认全部开启：

| 设置项 | 关掉之后 |
| --- | --- |
| 行号滚动同步 | 回到 Typecho 原生同步，文中有图时会错位 |
| 图片编号对照 | 两侧不显示 `#N` 和左侧缩略图 |
| 点击预览图片定位源码 | 点图不再跳转 |
| 光标段落跟随 | 光标移动时右侧不自动高亮 / 跟随 |
| 预览角标 | 不显示右下角的 `#N · 第 X 行` |
| 左侧缩略图条宽度 | 默认 68 px，挡地方就调小，建议 40–160 |

## 没生效？

- 先 **Ctrl+F5** 强刷一次，浏览器可能还缓存着旧的 JS / CSS。
- 下滑或点图总是弹回 #1：后台 `editor-js.php` 里还留着旧的手工补丁，把它还原成 Typecho 原版再强刷；服务器开了 OPcache 的话顺手重启一下 php-fpm。
- F12 看控制台，如果 `editor-sync.js` 报 404，多半是 `assets/` 目录没一起传上去。
- 图片左下角没缩略图：图片用了防盗链或跨域拒绝加载时会出现，正文预览不受影响。
- 窄屏单栏模式下预览默认隐藏，看不到角标，但点图定位仍可用。

停用插件即可恢复原生编辑器，删掉 `usr/plugins/EditorImageSync/` 目录就彻底清理干净。
